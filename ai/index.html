EV·01

Clickable electric car · 3D engineering model

A clickable electric car, twenty-four generations deep. Each generation had to beat the last on measured mass, drag, and consumption, and every part explains how it works and how it fails.

How it was built. I wrote the module contract, the design docs, and a retrospective after every generation on what the agents got wrong. Thirty-four automated checkers gate each build: part interference, triangle budgets, interface contracts, and prose rules.

Interactive planetarium · 119,625 real stars

A planetarium built on real catalogs: every star clickable, in one continuous zoom from the Moon to the edge of the observable universe, with NASA's archive of 4,689 real planetary systems.

How it was built. An autonomous agent loop improved it against a written quality bar and a record of vetoes. I reviewed every round and approved each deploy myself.

03 · CLAUDE CODE · PYTHON

Stock Evaluator

Index-benchmarked analysis · Python + Flask

One command turns a ticker into a full dossier, and every conclusion is measured against the alternative of just buying an index fund: bootstrap simulations, rolling entry windows, and reverse discounted-cash-flow tests.

How it was built. Specified as a scoring model first, then built and deployed as a web app. The free server sleeps between visits, so the first load can take a moment to wake.
